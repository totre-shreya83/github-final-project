# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description

This project contains a Bash script (`simple-interest.sh`) that calculates simple interest using the formula:

**Simple Interest (SI) = (P × R × T) / 100**

Where:

* **P** = Principal amount
* **R** = Rate of interest
* **T** = Time period in years

## Features

* Takes principal amount as input
* Takes rate of interest as input
* Takes time period as input
* Calculates and displays simple interest

## How to Use

1. Clone this repository.
2. Navigate to the project directory.
3. Run the Bash script:

```bash
bash simple-interest.sh
```

4. Enter the principal amount, rate of interest, and time period when prompted.

## Example

```text
Enter principal amount: 1000
Enter rate of interest: 5
Enter time period (in years): 2
Simple Interest = 100
```
